# Radar Ciudadano HNP - Archivo Ciudadano HNP

Plataforma digital de memoria, documentación, georreferenciación y seguimiento público de reportes ciudadanos del **Observatorio Comunitario Hechos No Palabras (HNP)** en el municipio de Cunduacán, Tabasco.

## 📋 Información Institucional
* **Proyecto:** Desarrollo de la Plataforma Digital de Memoria, Documentación y Seguimiento del Observatorio Comunitario (Radar Ciudadano HNP).
* **Unidad Receptora:** ALLS BASIC SUPPLY COMPANY SA DE CV.
* **Ubicación:** Cunduacán, Tabasco.

## 🏗️ Arquitectura del Repositorio
Repositorio estructurado bajo arquitectura desacoplada:
* `/docs`: Documentación técnica, requerimientos (SRS), diagramas de arquitectura, mapa del sitio y manuales.
* `/frontend`: Aplicación Web Progresiva (PWA) con soporte Offline-First (React + Vite + Tailwind CSS + Dexie.js + Leaflet.js).
* `/backend`: API RESTful y gestión de datos (Node.js + Express + PostgreSQL + Object Storage CDN).
